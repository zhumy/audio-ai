SESSION / WEEK3 SOURCE ROUTE

听觉系统与心理声学
怎么串成一次课？

这个 Session 只组织 WEEK3 源课件中的学习顺序：先建立声音进入听觉系统的通路，再观察听阈、响度、 临界频带和掩蔽，最后把音高、音色和 MP3 放到应用与检查中。具体知识请进入对应 Chapter。

Session 不替代 Chapter：这里解释为什么跳转、按什么顺序跳转；定义、图示、交互和边界都在 Chapter 中。

ROUTE MAP

WEEK3 源课件的关系路径

当前主题

先从“声音如何进入耳朵”开始

这一步让学生知道后面的心理声学现象不是凭空出现，而是建立在外中内耳的加工之上。

  • 进入完整 Chapter：外中内耳 查看外耳、中耳、内耳和图片材料。
  • 跳到精确锚点：耳蜗频率图 拖动频率，观察耳蜗位置变化。

当前主题

再问“什么容易被听见”

源课件接着进入听阈、响度和临界频带，把物理声级和主观听感区分开。

  • 跳到精确锚点：听阈与健康 查看听阈、audiogram 与辅听设备材料。
  • 跳到精确锚点：响度 操作等响曲线交互。
  • 跳到精确锚点：临界频带 观察中心频率与 ERB 带宽。

换一个方向

再到音高、音色和工程应用

源课件后半段从听觉约束转向音高、音色、掩蔽和 MP3，应拆到可复用 Chapter 后再由这里串起来。

  • 进入完整 Chapter：音高和符号音频 操作半音、MIDI、缺失基频。
  • 跳到精确锚点：音色 操作谐波和起音速度。
  • 回到心理声学：掩蔽与 MP3 观察掩蔽阈值和 MP3 应用。
