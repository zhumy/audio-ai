OVERVIEW

频域不是另一段声音，而是同一段声音的另一组坐标

这一页要解决的核心问题

时域波形告诉我们“声音在什么时候怎样变化”。频域进一步把这种变化拆成不同的旋转速度： 慢的成分对应低频，快的成分对应高频。理解频域以后，卷积滤波、频率响应、DFT、声谱图和后续 Mel 特征会连成一条线。

系统怎样改变声音？LTI 系统可由冲激响应描述，输出由卷积得到。
为什么用复正弦？复正弦经过 LTI 系统后频率不变，只改变复增益。
为什么需要 STFT？真实语音和音乐的频率组成随时间改变。

OBJECT

先把对象说清楚：从声压场到有限采样序列

三个层次不要混在一起

物理上，声音是空间与时间共同变化的声压场。麦克风固定在位置 rm 后，我们观察到的是一个连续时间信号。ADC 再按采样周期 Ts 把它变成离散序列。

p(r,t) → p(rm,t) → x[n] = Q{Gp(nTs)}

复用定义：采样率 Fs=1/Ts ，理想采样要求 Fs>2fmax 。这里的目标不是再解释“如何记录”，而是解释“记录以后如何分频率”。

符号小表

  • x[n]：离散时间音频序列。
  • h[n]：系统或滤波器的冲激响应。
  • X(f)：连续频率上的傅里叶表示。
  • X[k]：DFT 在第 k 个频率格点的系数。
  • X[m,k]：STFT 中第 m 帧、第 k 个频率格点。

CONVOLUTION

滤波器在时域上是什么：一个加权、延迟和相加的规则

时域滤波器就是冲激响应，也可以看成一组权重

在离散时间里，一个滤波器可以由冲激响应 h[n] 描述。它不是神秘的黑箱，而是一串权重：当前输入、前一个输入、再前一个输入各乘多少，最后相加得到输出。 对 FIR 滤波器来说，这个规则特别直接。

y[n] = (x*h)[n] = ∑m=-∞∞ x[m] h[n-m]

这条公式的读法是：把滤波器翻转并滑到当前时刻，找出与输入重叠的样本，逐点相乘，再把乘积相加。 因此“滤波”在时域上就是一组带延迟的加权求和；它在频域上才表现为低通、高通或带通。

低通：三点滑动平均

h= [13,13,13]

计算： y[n]= x[n]+x[n-1]+x[n-2] 3 。相邻样本被平均，慢变化保留，快速起伏更容易被抵消。

高通：一阶差分

h=[1,-1]

计算： y[n]=x[n]-x[n-1] 。常量或很慢的变化相减后接近 0，突变、边缘和快速振荡被突出。

带通：先去慢变化，再平滑过快变化

x → hHP → hLP → y

一个易懂做法是级联高通和低通：先用差分去掉直流和慢漂移，再用短平均抑制太快的抖动。 这样留下的是一段中间频率范围。真实工程里会用更精确的 FIR/IIR 带通设计。

时域与频域的连接

同一个 h[n] ，在时域看是加权求和，在频域看是频率响应 H(f) 。低通、高通和带通不是三种不同的“计算动作”，而是不同权重序列在频率轴上形成的不同选择效果。

PHASOR

复正弦是频域的天然基元：幅度与相位装进一个数

从真实余弦到复数表示

真实可测的声压可以写成余弦。为了同时记录振幅和相位，我们把它看成复旋转向量的实部：

x(t) = Re{Xejωt} , X=Aejφ , ω=2πf

|X| 是振幅， argX 是相位。复数没有增加新的声学物理量；它让微分、积分和滤波都变得可计算。 复用公式： 空间域附录中的复振幅解释。

物理声学中的频域意义

对单频声场 p(r,t)=Re{P(r)ejωt} ，时间微分对应乘以 jω 。这就是频域把动态方程变简单的原因。

展开：使用复数的核心优势

若直接使用正弦和余弦，每次微分、积分都要同时追踪振幅和相位。 使用复指数后，在单频稳态条件下，时间微分、时间积分和空间微分都变成简单的乘法或除法：

时间微分
∂∂t ⇔ jω
对复指数求时间导数，只需乘以 jω。
时间积分
∫dt ⇔ 1jω
当 ω≠0 时，积分对应除以 jω；直流项与积分常数需另行处理。
沿 +x 的空间微分
∂P∂x =-jkP
这里采用沿 +x 传播的平面波约定 P(x)=P0e-jkx。

因此，时域中的线性化动量方程（牛顿第二定律）

ρ ∂u∂t = - ∂p∂x

在 p(x,t)=Re{P(x)ejωt} 和 u(x,t)=Re{U(x)ejωt} 的约定下，可以直接变成复振幅之间的代数关系：

jωρU = - ∂P∂x

一句话概括：复数表示把振幅和相位打包在 P(x) 中，把微分和积分变成乘除法；计算完成后取实部，才得到真实声压。

FOURIER

傅里叶变换：用复指数询问信号里有哪些旋转速度

投影，也是相关性测量

拿一个频率为 f 的复指数与信号相乘并跨时间累加，就像在问：“这段声音里有没有这个频率？强不强？相位在哪里？” 频率匹配时，累加后留下较大结果；频率不匹配时，正负摆动大体抵消。

X(f) = ∫-∞∞ x(t) e-j2πft dt
模长|X(f)| 表示该频率有多强。
相位argX(f) 表示该频率怎样对齐。
功率 |X(f)| 2 描述能量分布。

为什么滤波在频域里更直观

时域中的卷积，在频域中变成乘法。滤波器的频率响应 H(f) 直接说明每个频率被放大、削弱或相移多少。

y(t)=x(t)*h(t) ⇔ Y(f)=X(f)H(f)
展开：由卷积推到频谱相乘

从连续卷积 y(t)=∫x(τ)h(t-τ)dτ 出发，对 y(t) 做傅里叶变换，并令 u=t-τ ，积分可以分解成 X(f) 与 H(f) 的乘积。

DFT

计算机真正算的是有限序列在有限频率格点上的投影

Fourier Transform、DFT 与 FFT 的分工

实际音频分析面对的是有限长度序列 x[0],x[1],…,x[N-1] 。DFT 把这 N 个样本映射到 N 个离散频率格点。

X[k] = ∑n=0N-1 x[n] e-j2πkn/N

FFT 不是新的变换，而是快速计算 DFT 的算法。课堂解释频谱时，先说清楚 k 是格点索引，不直接等于 Hz。

频率格点与分辨率

fk = kFsN , Δf = FsN = 1Tobs

最高可表示频率由采样率决定；真正的频率分辨能力主要由有效观察时长和窗函数决定。 只做 zero-padding 会让图上的频率采样更密，但不会增加原记录中的真实信息。

改变什么 主要改变什么 不自动保证什么
增大采样率 Fs 可表示的最高频率提高。 不自动提高相邻低频的可分辨能力。
增大窗口长度 N 观察时间变长，频率格点变密。 不自动提高最高可表示频率。
只做 zero-padding 图上采样点更密，峰位置更容易插值。 不增加原始记录中的真实频率信息。

TIME-FREQUENCY

真实声音会变：从整段频谱走向 STFT 与声谱图

整段 DFT 只回答“有什么频率”，很难回答“何时出现”

语音、音乐和环境声通常不是稳定不变的。STFT 用滑动窗口反复做 DFT，把频率分析放回时间轴上。

X[m,k] = ∑n x[n] w[n-mR] e-j2πkn/N
  • w[n-mR]：第 m 帧的分析窗。
  • N：每帧 FFT 长度。
  • R：hop size。
  • |X[m,k]|：时间帧和频率格点附近的强度。
时间侧条件或操作 频率侧结果 直觉
时间连续、非周期 连续频谱 X(f) 理论上所有频率都可以被询问。
时间周期 离散线谱 只在基频整数倍上有傅里叶级数系数。
时间采样 频谱周期复制 复制间隔为 Fs；重叠就产生混叠。
时间截短或乘窗 原频谱与窗频谱卷积 截断导致主瓣、旁瓣与频谱泄漏。
频率采样 时间序列周期延拓 DFT 把有限记录视为一个隐含周期。
