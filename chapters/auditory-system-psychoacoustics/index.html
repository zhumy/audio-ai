AUDITORY CHAIN

外耳、中耳、内耳：声音进入听觉系统的整体路径

不是被动麦克风

本章的第一条主线是：耳朵不是把空气压力原样交给大脑。耳廓和耳道改变方向相关频谱， 中耳把鼓膜振动传给卵圆窗，内耳再把机械振动转成神经活动。

  • 外耳：收集声波并引入方向相关滤波。
  • 中耳：鼓膜和听小骨完成机械耦合与阻抗匹配。
  • 内耳：耳蜗基底膜把频率组织成空间位置。

OUTER EAR / 外耳

外耳先改变进入耳道的声谱

外耳不是一个简单的入口。耳轮、耳甲腔、耳屏和耳廓褶皱会让不同方向、不同频率的声音在进入外耳道之前已经带上滤波痕迹。 这为后面的方向判断和 HRTF 埋下第一层线索。

  • 耳廓形状参与方向相关滤波。
  • 外耳道把声波引向鼓膜。
  • 这一步仍然是声学空间中的变化，还没有进入机械换能。

MIDDLE EAR / 中耳

中耳把鼓膜振动传给卵圆窗

声波推动鼓膜，锤骨、砧骨和镫骨把机械运动向内传递。这个过程不是“声音继续往里走”这么简单， 而是空气振动到内耳液体振动之间的机械耦合与阻抗匹配。

  • 鼓膜先把空气压力变化转成机械振动。
  • 听小骨链传递并调节振动。
  • 镫骨推动卵圆窗，声波进入内耳液体系统。

INNER EAR / 内耳

内耳把频率组织成耳蜗上的位置

进入内耳后，耳蜗不是简单记录“有多少 Hz”，而是让不同频率在基底膜上形成不同响应位置： 高频更靠近基底端，低频能传播到更靠近顶端的位置。

  • 顶区更偏向低频响应。
  • 基底区更偏向高频响应。
  • 频率到位置的映射，是后面听觉滤波器、临界频带和掩蔽的生理直觉来源。

AUDITORY FILTER

听觉滤波器：从耳蜗实验到滤波器组

不是直接把耳蜗画成 FFT

耳蜗的构造提示我们：不同频率会在基底膜上形成不同响应。但在课程中更重要的一步， 是看生理学和神经学实验如何测量这种频率选择性，再把实验结果经验总结成一组带通的听觉滤波器。 Gammatone filter 就是常用的经验模型之一，用来模拟耳蜗基底膜附近的频率选择性。

因此，耳蜗不能简单理解成“带分频功能的 ADC”。更贴近课程直觉的说法是： 它像一个连续滤波器组前端，同时伴随自动增益控制、动态压缩和神经脉冲编码； 内毛细胞再把机械运动转换成神经信号。

Q≈7.6中心频率 / 带宽

滤波器组从实验曲线到可计算前端

经验链条

  • 生理观察：基底膜和听神经对不同频率有选择性响应。
  • 实验测量：通过响应曲线、调谐曲线和心理声学任务估计每个频率附近的有效通带。
  • 经验拟合：用 ERB 标尺和 Gammatone 这类模型，把连续的听觉响应整理成滤波器组。
  • 工程使用：后续很多音频特征并不是直接复制耳蜗，而是借鉴“按感知频带组织信息”的思想。

Gammatone 的角色

Gammatone 不是从第一性原理严格推导出来的耳蜗方程，而是对实验响应形状的经验拟合。 它常被写成一个带有 gamma 包络和中心频率振荡的冲激响应，用来构造符合 ERB 宽度变化的听觉滤波器组。

g(t) = tn-1 e-2πbt cos(2πfct)

这里的学习重点不是记住公式形状，而是理解抽象过程：先观察耳蜗和听神经的频率选择性， 再用经验模型把这些响应整理成可计算、可复用的滤波器组。

THRESHOLD AND HEALTH

听阈、听损与助听设备

听阈曲线：不同频率的可听边界

同样的声压级在不同频率上不一定同样容易被听见。听阈曲线把“刚好能听到”的边界画成频率函数： 人耳通常在中频区域更敏感，低频和很高频需要更高声压才容易被察觉。

这条曲线也提醒我们，可听性不是单一 dB 数值决定的，而是频率、声级和听觉系统状态共同决定的结果。

Audiogram：把听损变成可读图形

听力图通常横轴是频率，纵轴是听阈级。曲线越往下，表示需要更大的声音才听得见； 如果高频区域明显下降，常见结果就是辅音、齿音、细节和空间线索更容易丢失。

它不是简单给出“听力好或不好”，而是指出哪些频段出了问题，从而决定后续补偿应该集中在哪些频带。

听力测试：控制环境中的阈值测量

听阈需要在受控声学环境中测量。隔声室、校准耳机和标准化测试流程用于减少背景噪声、 房间反射和设备差异带来的干扰。

测试得到的不是“自然听音体验”的全部，而是一组可重复比较的频率阈值，为诊断和设备调试提供基准。

助听设备：放大、补偿与神经刺激

助听器通常面向残余听力做频带增益、动态压缩和反馈控制；人工耳蜗则在毛细胞功能严重受损时， 通过电极阵列直接刺激听神经相关通路。

两类设备都不是“把声音变大”这么简单。它们需要根据听阈、频率分辨率、响度增长和使用场景， 在可听性、舒适度和语音清晰度之间折中。

  • 啸叫：扬声器输出再次被麦克风拾取会形成声反馈，增益越高、佩戴越松，越容易出现尖锐啸叫。
  • WDRC：宽动态范围压缩需要把小声放大、把大声压住，同时尽量保留语音细节和响度自然感。
  • 降噪：真实环境里噪声、混响和多人说话常混在一起，算法要降低干扰，又不能把目标语音削薄或产生明显失真。

LOUDNESS

响度：同一声压不等于同一听感

等响曲线的观察

等响曲线把“听起来一样响”转换成一组声压级曲线。1 kHz 常作为参照频率；当频率偏向低频或很高频时， 要达到相同响度通常需要不同的 dB SPL。

这说明响度不是声压级的直接同义词。声压是物理量，响度是经过听觉系统频率敏感性、声级范围和听觉压缩后形成的感知结果。

可选参考：复杂信号的感知响度计算

对音乐、语音、环境声这类复杂信号，响度计算不能只查一条等响曲线。算法会先把输入声信号校准到声压级， 再进入频带分析、听觉激励、特定响度和时间整合，最后输出整体 loudness、specific loudness 或时变百分位响度。

ISO 532-1 / Zwicker 框架

这一路线以临界频带、Bark 标尺和特定响度为核心，适合从声压谱或时域信号估计整体响度。 MATLAB 默认使用这个方法，并支持 stationary 与 time-varying loudness。

  1. 输入校准：从音频波形和采样率进入时，需要用 microphone calibration factor 把数字幅度换算到声压；也可以直接输入 1/3 octave SPL。
  2. 1/3 倍频程分析：把信号转换成 25 Hz 到 12.5 kHz 的 28 个 1/3 octave 频带声压级，输入 SPL 要使用 Z-weighting。
  3. 低频修正与能量合并：对低频段做去强调或修正，再把相邻频带能量按规则合并，得到更接近听觉前端的频带级。
  4. 核心响度：把频带声级转换为 core loudness，表示各临界频带中由物理能量诱发的初始响度贡献。
  5. Bark 轴展开：把 core loudness 映射到 0.1 到 24 Bark 的 specific loudness 分布。
  6. 频率扩展与积分：用频率扩展斜率模拟掩蔽和频带间影响，再对 specific loudness 积分得到总响度，单位通常是 sone。
  7. 时变响度：对非平稳声音加入 temporal weighting，输出随时间变化的 loudness，并可统计 percentile loudness。

ISO 532-2 / Moore-Glasberg 框架

这一路线更像双耳听觉模型：它从外耳/中耳/耳蜗传递出发，先计算 excitation pattern， 再转换为特定响度，并通过 binaural inhibition 合成双耳结果。MATLAB 中它对应 Method="ISO 532-2"。

  1. 输入校准：同样需要把波形换算到声压；若输入 1/3 octave SPL，则使用 25 Hz 到 16 kHz 的 29 个频带，并保持 Z-weighting。
  2. 声场条件：根据 free、diffuse、eardrum 或 earphones 等记录/播放条件，选择进入耳道与耳膜模型的修正方式。
  3. 外周听觉传递：每个耳道通道依次经过 tympanic membrane、中耳和耳蜗模型，得到更接近内耳机械响应的频率表示。
  4. 激励模式：耳蜗模型输出 excitation pattern，用来描述不同听觉滤波器位置上的有效激励。
  5. 特定响度：把 excitation 映射到 Cam 标尺上的 specific loudness；MATLAB 返回的维度对应约 1.8 到 38.9 Cam。
  6. 双耳整合：左右耳不是简单相加，而是经过 binaural inhibition 模型整合，形成一个双耳响度估计。
  7. 整体响度：沿 Cam 轴积分 specific loudness，得到总 loudness。这个方法主要面向 stationary loudness，而不是 ISO 532-1 那种时变百分位输出。

MATLAB Audio Toolbox 的 acousticLoudness 函数把这两类 ISO 方法作为可选算法入口。它的典型输出包括总 loudness、specific loudness； 当 ISO 532-1 开启 TimeVarying 时，还可以得到 percentile loudness。

MASKING

掩蔽：听不见不代表不存在

频域掩蔽：同一听觉滤波器里的竞争

当目标声在频率上靠近较强的掩蔽声，并且声级低于简化掩蔽阈值时，它可能存在于信号中但不容易被听见。 这不是声音消失，而是可闻性边界发生了变化。把这个现象和前面的听觉滤波器放在一起看， 声音是否“可闻”，取决于频率距离、声级差、滤波器带宽和上下文，而不是只看频谱上有没有那条线。

时间上的掩蔽：前向与后向

掩蔽不只发生在同一时刻。强声音出现后，听觉系统需要一小段时间恢复，后面紧跟的弱声音可能更难被听见， 这叫前向掩蔽。反过来，如果一个强声音很快跟在弱声音之后，后来的强事件也可能干扰前面弱事件的知觉， 这叫后向掩蔽。

  • 前向掩蔽 Forward masking：掩蔽声先出现，目标声后出现。
  • 后向掩蔽 Backward masking：目标声先出现，强声很快随后出现。
  • 时间整合：耳朵不是逐点读取波形，而是在时间窗口内整合、恢复和解释声音事件。

机制上的掩蔽：energy 与 information

Energy masking 更接近外周听觉滤波器的能量竞争：目标和干扰在频率、时间或空间上重叠， 使目标声在早期听觉表示中被压住。Informational masking 则更偏向中枢层面的混淆： 即使目标和干扰在能量上可以分开，听者仍可能因为注意、相似性、语义或声源组织失败而听不出目标。

  • Energy masking：主要来自听觉前端的频带/时间重叠。
  • Informational masking：主要来自对象分离、注意选择和判断策略的困难。
  • 边界：真实听觉任务里两者常同时存在，不应把所有听不清都解释成能量遮盖。

掩蔽描述频域、时间域和知觉组织层面的可听性下降：目标声仍然物理存在，但在听觉表示或判断过程中变得不突出。

PERCEPTUAL CODING

从掩蔽到 MP3：把“听不出来”变成工程能力

为什么压缩不能只是删采样点

未压缩 CD 音质立体声大约是 1411 kbps，一首几分钟的歌曲很容易达到几十 MB。 MP3 的关键不是随机删掉波形点，而是让编码器估计听阈、临界频带和掩蔽阈值， 判断哪些频率成分更容易被听到，哪些细节可以用更少比特表示。

  • 心理声学模型：估计当前声音背景下哪些量化噪声更不容易被听见。
  • 比特分配：容易听出的频带保留更多精度，被掩蔽的频带减少比特。
  • 工程意义：感知编码把“信号里有什么”转换成“人实际能听出什么”。

从心理声学模型到码流

编码器先把音频分解到频带或变换域，再估计当前片段的可闻性边界。量化噪声只要被控制在较难察觉的区域， 文件体积就能显著下降，同时保留主要听感结构。

  • 1987：EUREKA EU147 数字音频广播项目形成研究联盟。
  • 1992/1993：MPEG-1 Audio Layer III 成为技术基础。
  • 1995-1998：.mp3 命名后进入个人电脑和便携音乐时代。

心理声学在这里进入工程语境：掩蔽不是孤立现象，而是感知音频编码能够大幅减少数据量的关键依据。
