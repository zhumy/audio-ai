01 / ACOUSTICS

声波是纵波，又称疏密波

发声体的机械振动会推动相邻空气微团前后往复运动，形成一段段压缩与稀疏交替的扰动。 这些疏密变化沿传播方向向外传递，所以声波是纵波，又称疏密波； 传播的是压强扰动与能量，而不是一团空气从声源一路跑到耳朵。

声压与声压级 SPL

当压缩区和稀疏区经过某个固定观察点时，该点的空气压强会围绕静态大气压上下变化。 声压 p(t) 就是这种瞬时压强偏离，单位 Pa。 声压级以空气中的参考声压 p0 = 20 μPa 表达量级。

p(t) = P(t) - Patm Lp = 20log10 ( prms p0 )  dB SPL

频率与正弦声压波形

若声源做理想简谐振动，固定观察点记录到的声压变化可以近似为正弦波。 一次“压缩 → 稀疏 → 再压缩”对应一个周期 T，每秒重复次数就是频率 f，单位 Hz。

p(t) = Asin(2πft+φ) f=1T  [Hz]

速度与声强 Intensity

声速 c 是波的传播速度， 20°C 空气中约 343 m/s； 质点速度 u(t) 是空气微团的局部往复速度。声强 I 描述单位面积通过的声功率，瞬时声强来自声压与质点速度的共同作用。

i(t) = p(t) u(t) , I= ⟨p(t)u(t)⟩ 远场 / 平面行波： U≈Pρc , I= prms2 ρc

引申理解 / LOCAL MOTION, GLOBAL PROPAGATION

空气粒子不远行，声能会向外传播

经典声学中，空气介质质点 particle 在平衡位置附近往复运动， 机械波携带声能量向外辐射。

理想点声源的球面扩散

若点声源在无反射、无吸收的自由三维声场中均匀辐射声功率 W， 距离为 r 的位置接收到的能量分布在半径为 r 的球面上：

S=4πr2 I(r) =WS = W 4πr2

所以声强满足 I∝1r2 。距离加倍时：

I(2r) = I(r) 4 ΔLI = 10log10(14) ≈-6.02 dB

又因为远场中 I= prms2 ρc ， 声压幅度随距离近似按 1r 衰减。距离加倍时声压变为 12：

ΔLp = 20log10(12) ≈-6.02 dB SPL

这个“每倍距离约 -6 dB” 只适用于理想点声源、自由场、远场近似； 教室、房间反射、声源指向性和空气吸收都会让实际读数偏离它。

从波动方程到近场 / 远场

球面波：把声压、声压梯度和质点速度连起来

更完整地看，声压不是只随时间变化的曲线，而是同时依赖空间位置和时间的场： p(r,t) 。 下面这条推导线把“完整声压场”一步步化成“远场 / 近场中的声压-质点速度关系”。

完整声压场 波动方程 空间声压 空间梯度 质点速度
  1. 完整声压场满足波动方程

    在均匀、无损、无声源的空气中，声压扰动满足线性声学波动方程。 它表达的是：空间中的弯曲变化和时间上的加速变化彼此约束，扰动因此以声速 c 传播。

    ∇2 p(r,t) - 1c2 ∂2 p(r,t) ∂t2 =0
  2. 固定频率时，拆出时间因子并引入波数

    对单一频率的简谐声场，所有位置共享同一个时间因子 ejωt ； 剩下的 P(r) 记录空间中的幅度和相位。 k 称为波数，表示单位距离累积多少相位：

    p(r,t) = Re { P(r) ejωt } k=ωc = 2πλ 代回波动方程后，空间声压满足 Helmholtz 方程： ∇2P +k2P =0
  3. 点声源球面波的空间声压与空间梯度

    理想点声源向外辐射时， 1r 描述幅度随距离衰减， e-jkr 描述相位随距离累积。对空间声压求径向梯度，就得到声压在空间上变化的快慢：

    P(r) = A e -jkr r dPdr = P(r) (-jk-1r)
  4. 空间梯度通过动量方程决定质点速度

    这一步来自牛顿第二定律：空气微团两侧的声压不同，会产生净压力并推动它加速。 写成连续形式，就是线性化动量方程；再代入简谐形式，时间求导等价于乘以 jω。

    ρ ∂u ∂t = -∇p jωρU = - dPdr U(r) = P(r) ρc [ 1 + 1 jkr ]

kr 是传播到距离 r 所累积的相位，也可理解为用波长衡量的无量纲距离。 当 kr≫1 时， 1jkr 很小，回到远场近似；当 kr 不大时，声压和质点速度不再简单同相同幅比例，这就是近场需要单独讨论的原因。

EXTENDED READING / WHO IS LISTENING?

声级计的“听感刻度”，默认以人耳为对象

dB SPL 描述物理声压；但环境噪声与听力安全场景中的声级计常显示 dB(A)，也就是经过 A-weighting 的读数。A 加权压低人耳不敏感的低频和高频， 以近似普通人类听觉对频率的响应。因此，一台用来评估人类听感或人类听力风险的声级计， 并不等价于“猫耳声级计”或“狗耳声级计”。

HUMAN / 人 约 -10 dB SPL

最敏感区域约在 2–4 kHz；日常 A 加权主要围绕人耳听觉响应设计。

CAT / 猫 约 -3 dB SPL

在 8–16 kHz 左右非常敏感；在较高声级下，可听范围可延伸到约 75–85 kHz。

DOG / 狗 约 0 dB SPL

最敏感区域约在 2–8 kHz；在 60 dB SPL 参考下，可听高频约延伸到 45 kHz。

如何理解这组数字：动物并不是在所有频率上都比人耳更敏锐； 它们拥有不同形状的听力图（audiogram），尤其能感知许多人类听不到的高频声音。 比较“谁听得更轻”时，必须同时说明声音的频率与测试方法。

02 / TRANSDUCER

MEMS 电容式麦克风换能

麦克风有多种换能原理。本课以手机、耳机与智能设备中常见的电容式 MEMS 麦克风为典型： 声压作用在微加工振膜上，振膜与背板构成可变电容，间距变化引起电容量变化。 封装内的 ASIC 提供偏置与读出电路，再将微弱信号变为模拟输出，或进一步转换为数字输出。

麦克风灵敏度 Sensitivity

灵敏度描述给定声压能产生多少输出。模拟输出麦克风通常在 1 kHz、 1 Pa （即 94 dB SPL） 条件下标为 dBV/Pa；数字输出器件也常给出 dBFS/Pa。

S= 20log10 ( Vout 1 V )  dBV/Pa

模拟输出示例： -38 dBV/Pa 表示 1 Pa 输入时约产生 12.6 mVrms 输出； 灵敏度越负，同样声压下电输出越小。

核心原理没有改变：MEMS 麦克风仍然把“声压造成的机械振膜位移”变成“电容量变化”。 不同之处是可动结构被微加工在硅片上，并与偏置、放大及输出转换所需的 ASIC 集成到微型封装内。 ST 的器件既有顶开孔也有底开孔设计，声孔位置会影响声音进入 MEMS 结构的路径。

沿着剖面图读懂 MEMS 封装

01 · 声孔 Port声音从顶部或底部的开孔进入；图中左右两种封装首先改变的就是入声方向。
02 · 前 / 后声腔Front chamber 接收外界声压，back chamber 为振膜背侧提供声学容积，两者共同影响响应。
03 · MEMS 振膜微加工的轻薄可动结构受声压差驱动而位移，这是空气振动向机械运动的耦合点。
04 · 空气间隙 d(t)振膜与固定背极之间的距离改变，使电容 C(t)=εAd(t) 随声音变化。
05 · 背极与 ASIC固定电极感知微小的 ΔC(t)，同封装 ASIC 负责偏置、低噪声读出与信号调理。
06 · 输出形式模拟 MEMS 输出电压交给外部 ADC；数字 MEMS 可在芯片内转换后直接输出 PDM 数据流。

03 / A/D CONVERSION

ADC 采样与量化

前置放大器或 MEMS 内部 ASIC 将麦克风的微弱信号调理到 ADC 可处理的范围。 ADC 做两件事：先在离散时刻“抓住”模拟电压，再把连续电压映射到有限个数字码。 因此未经声学校准的波形 x[n] 首先代表数字幅度，不直接等于 Pa 或 dB SPL。

采样t=nTs，只在这些时刻读取电压。
量化x[n]=QB{Gvmic(nTs)}，QB 表示 B bit 量化器。
位深2B 个等级，Δ≈2VFS2B。
dBFS满幅为 0 dBFS；样本峰值 0.5 约为 -6 dBFS。
Anti-alias LPF→ Sample / Hold→ Comparator→ Quantizer→ Code

传统多 bit PCM ADC

一次采样，输出 B bit 数字码

S/H→SAR / Flash→B bit PCM
PCM x[n]：对应图中 14 个蓝色采样点 [ +2, +3, 0, -2, -3, -2, 0, +2, +3, 0, -2, -3, -2, +3 ]

每个采样点直接对应一个多 bit 幅度码；本例序列长度与图中的蓝色采样点数量一致。

1-bit σ-δ / PDM

极高频率的 1 bit 脉冲，靠密度表示幅度

Σ 积分器→1 bit 比较器→PDM 反馈 Δ：把上一次 1 bit 输出减回输入端
σ-δ / PDM bits：本例 4× 过采样，56 bit 1110 1111 1010 0010 0000 0010 1010 1110 1111 1010 0010 0000 0010 1111

PDM 的 bit 率通常远高于 PCM 采样率；这里示意为 fPDM=4fPCM ，实际数字 MEMS 常更高。数字低通和抽取会把 PDM 转成 PCM。

如何读这两个序列

上面的 PDM 串是为了读图而构造的脉冲密度示意，不是由 PCM 序列唯一严格推导出的结果。 真正的 σ-δ 调制器包含积分反馈，具体 bit 串还会受过采样倍数、调制器阶数、初始状态和反馈量化器定义影响。

+31111 +21110 01010 -20010 -30000

在本例中，为了让同学能从图例读懂关系，我们把每个 PCM 样本替换成 4 个 PDM bit： 幅度越高，4-bit 小块中 1 越多；幅度越低，0 越多。 14 个 PCM 样本因此对应 14 组小块，共 56 个 PDM bit。

不要把三种幅度参考混在一起

dB SPL空气中的声压级参考 20 μPa
dBV/Pa麦克风灵敏度1 Pa 输入产生的电压
dBFS数字音频电平参考 ADC/文件满幅

只有知道麦克风灵敏度、前置增益和 ADC 标定关系，数字 dBFS 才能换算为现场 dB SPL。

读一张时域图时，看三件事

横轴是时间，纵轴是幅度，外形是变化方式。

  • 幅度：不是“音高”；录音波形的纵轴通常是归一化数字值，校准后才能对应声压。
  • 周期：纯音会呈现稳定重复；周期越短，重复越快。
  • 包络：敲击会迅速升起再衰减，体现事件发生的时间结构。

STATISTICS

两个基础统计量：RMS 与 ZCR

RMS

均方根：平均能量尺度

RMS(x) = 1N Σ n=0 N-1 x[n] 2

波形有正有负，直接求平均会相互抵消。先平方使其都为正， 再平均并开方，得到与原始幅度具有相同量纲的整体强度指标。

适合回答：这个时间片段整体有多强？敲击的衰减是否很快？
ZCR

过零率：变化快慢的粗略线索

ZCR(x) = 1N-1 Σ n=1 N-1 1 [ sign(x[n]) ≠ sign(x[n-1]) ]

每当相邻样本的符号改变，波形就跨过零线一次。 粗糙噪声或较快振荡通常产生较高 ZCR；低频、平滑信号通常较低。

适合回答：波形是否快速翻转？它可能更噪声化还是更平滑？
分帧计算

真实音频随时间变化，常把信号切成短帧，逐帧得到 RMS/ZCR 轨迹。

尺度意识

RMS 随录音增益变化；比较样本前应考虑音量归一化和录制条件。

不要过度解读

相同 RMS 或 ZCR 的声音仍可能听起来完全不同。

HUMAN HEARING

耳朵也在时间中分析声音

ONSET

起始瞬态

敲击、拨弦、爆破音之所以容易被辨认，部分原因在于声音开始的一瞬间包含鲜明线索。 只看长期平均能量会淡化这种信息。

ENVELOPE

包络与节奏

响度随时间的起伏帮助我们感知语音节奏、音节边界和音乐律动。 RMS 的逐帧轨迹可以粗略描写这种包络。

INTEGRATION

短时整合

听觉不会逐采样点“阅读”声音，而是在短时间范围内整合能量与变化； 因而音频分析常采用窗口和帧作为基本单位。

TIMING

时间差线索

两耳接收声音的微小时差可以支持定位。虽然本章尚不展开空间听觉， 但它提醒我们：声音中的时间结构具有知觉意义。

注意：人耳听觉远不等于 RMS 或 ZCR 计算器。这里的统计特征只是便于机器使用的低阶描述， 它们能够对应一部分听觉现象，却不能完整还原听觉表征。

本章最后一个问题

两个声音的 RMS 很接近、ZCR 也接近，它们会听起来一样吗？

不会。长笛和纯音可能都平稳持续，两个音符也可能具有相似强度， 但它们的音高和音色仍明显不同。时域特征告诉我们“何时、整体多强、是否快速变化”， 却没有直接拆开声音由哪些频率成分构成。

音高

周期重复指向音高，但复杂声音需要更系统的频率描述。

音色

不同谐波构成决定音色，仅凭 RMS/ZCR 很难区分。

共振峰与频带

语音和环境声的辨识依赖能量集中在哪些频段。
