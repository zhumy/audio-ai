00-08 MIN / LISTEN FIRST

同一段声音，为什么需要换一个坐标系？

开场观察

两个波形看起来相近时，频率组成可能完全不同。

先回看第一章：波形、RMS、ZCR 能描述能量和变化速度，却很难直接回答 “它主要由低沉共鸣、清晰语音，还是尖锐摩擦声组成”。频域提供的不是另一段声音， 而是同一段声音的另一种坐标表示。

有哪些频率？声音中包含哪些正弦基元或频带能量。
强弱在哪里？能量集中在低频、中频还是高频。
听起来怎样？频率位置如何影响厚度、清晰度、明亮度与刺耳感。

同一信号的两种视图

08-28 MIN / REPRESENTATION

什么是频域：把声音拆成频率成分

01 / FREQUENCY DOMAIN

频域不是“新声音”，而是同一信号的组成清单

时域关注 x[n] 在第几个采样点上取什么值；频域关注这段序列可以由哪些不同频率的正弦或复指数基元叠加而成。 对声音来说，这个转换尤其有用，因为音高、音色、语音清晰度和噪声质感都和频率分布密切相关。

01

周期与频率

周期越短，频率越高；频率单位是 Hz，表示每秒重复次数。

02

正弦基元

复杂声音可看作多个不同频率、幅度和相位的基元叠加。

03

频谱

频谱展示每个频率位置上的强度，常看幅度谱或功率谱。

04

听觉解释

频谱峰值、能量重心和频带分布会影响我们听到的厚度、清晰度与明亮度。

频率与周期

若一个周期为 T 秒，频率为每秒重复次数。

f=1T

幅度与相位

幅度说明某个频率成分有多强；相位说明这个成分在时间上从哪里开始。

Asin(2πft+φ)

频谱

频谱可理解为“频率索引上的能量分布图”，常用来比较声音的组成差异。

x(t)↔X(f)

28-50 MIN / FOURIER TO DFT

傅里叶变换与 DFT：从连续想法到离散计算

02 / FOURIER TRANSFORM

傅里叶变换

傅里叶变换把时间函数映射为频率函数： 每个频率位置的复数系数同时携带幅度和相位信息。 在课堂中先建立直觉，再进入公式。

X(f) = ∫-∞∞ x(t) e-j2πft dt
03 / DFT

离散傅里叶变换

计算机处理的是有限长度采样序列，所以使用 DFT。 它把 N 个采样点映射到 N 个频率格点。

X[k] = ∑n=0N-1 x[n] e-j2πkn/N
04 / SPECTRUM

幅度谱与功率谱

初学阶段先看 |X[k]| 理解“哪个频率强”；后续再比较功率谱、对数幅度和 dB 标度。

幅度谱成分强弱

相位谱时间对齐

05 / FREQUENCY BINS

频率格点与分辨率

第 k 个 DFT 格点对应的实际频率由采样率 Fs 和窗口长度 N 决定。

fk = kFsN , Δf=FsN

50-67 MIN / FREQUENCY AND HEARING

频率位置改变，听觉印象也改变

LOW / 20-250 Hz

低频：重量、共鸣与身体感

低频常决定鼓、低音、引擎、风噪等声音的厚度和震动感。 能量过多会显得轰鸣，能量不足会显得单薄。

MID / 250 Hz-4 kHz

中频：语音主体与可辨识信息

人声、乐器主体和很多环境声线索集中在中频。 这一范围往往关系到“听得懂”和“听得近”。

HIGH / 4-20 kHz

高频：明亮、摩擦与空气感

高频带来齿音、擦音、边缘、明亮度和空间空气感。 过多时可能刺耳，过少时会显得闷或缺少细节。

课堂处理方式

这些频段边界只是教学用粗分。真实听感还会受到声压级、音色、持续时间、 听音设备、房间响应和个人听力差异影响。

67-78 MIN / EQUAL LOUDNESS

等响度曲线：同样的 dB，不一定同样响

01 响度不是声压级的简单复制

相同 dB SPL 的低频、中频和高频，听起来可能并不一样响。

02 低频通常需要更高声压

在较低响度水平下，人耳对低频不如中频敏感。

03 中高频影响清晰度与警觉感

人耳在约 2-5 kHz 附近较敏感，语音清晰度与很多告警声也常利用这一范围。

78-88 MIN / FILTERS AND FEATURES

基于频率的特征：滤波器、滤波器组与进阶位置

基础章内保留

频带滤波的直觉

先讲低通、高通、带通的听觉效果：保留或削弱某些频率范围， 让学生把“频谱图上的区域”与“听到的变化”对应起来。

章末过渡

滤波器组与 Mel 滤波器组

把完整频谱压缩为一组频带能量，为 Mel 频谱、MFCC 和后续机器学习特征做准备。 这一部分适合作为第二章的收束，也可以拆到下一章展开。

进阶内容候选

听觉滤波与耳蜗直觉

Gammatone、临界带、耳蜗压缩与适应可作为进阶模块。 若课程时间紧，第二章只给动机和图像，不在这里推导模型。

结构建议

  1. 第二章主体讲“频域表示 + DFT + 频段听感 + 等响度曲线”。
  2. 章末用一页介绍“频带滤波 / Mel 滤波器组”作为特征工程入口。
  3. 更完整的听觉滤波、耳蜗和 Gammatone 放入后续进阶章节。

88-90 MIN / CHECKOUT

本章结束时，学生应该能说清楚什么？

表示频域是同一声音的频率组成视图，不是替代时域。
计算DFT 如何把有限采样序列映射到频率格点。
听感低频、中频、高频为何对应不同的听觉特征。
感知等响度曲线说明人耳对不同频率的敏感度不同。
特征滤波器组如何把频谱变成更紧凑的机器学习输入。
