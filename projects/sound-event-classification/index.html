PROJECT / SOUND EVENT CLASSIFICATION

声音事件分类
与交互展示

项目把前四章的共同语言落到一个任务中：选择声音类别，提取时域、频域和听觉相关特征， 建立一个简单分类器，并用页面展示结果和错误案例。

项目路线

定义声音事件

提取特征

训练基线模型

解释错误案例

PROJECT STRUCTURE

先做一个能解释的基线，而不是追求复杂模型

01

数据

采集或整理少量声音事件样本，如敲击、摩擦、语音、环境声。

02

特征

比较 RMS、ZCR、频谱质心、带宽、Mel 能量等特征。

03

模型

先用 KNN、SVM 或小型神经网络建立可解释基线。

04

展示

页面中展示音频、波形、频谱、预测标签和错误分析。
